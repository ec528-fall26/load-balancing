# Experiments

[Running the experiments](../docs/design-document.md#4-running-the-experiments)
lists the commands, expected outputs, and reference evidence.

Run these scripts from the repository root. `results/` contains the reference
captures used for the documented results. For a new run, use a fresh directory
ending in `-rerun` or a report ending in `-rerun.json` under `results/`.
Git ignores those paths. Some scripts replace files at the chosen output
location, so keep it separate from the reference capture.
